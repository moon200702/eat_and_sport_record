# Android 測試版

[下載 日常食動 1.1.0 Debug APK](eat-and-sport-record-1.1.0-debug.apk?raw=true)

- 支援 Android 8.0（API 26）以上。
- 包含圖片／影片筆記、搜尋、SQLite 與完整 ZIP 備份匯入匯出。
- 已通過 APK 建置、47 項自動測試及 Android Lint。
- 此檔為 Debug 簽章測試版；真機影音與文件供應程式行為仍需實機驗證。

`SHA256SUMS` 提供檔案驗證。在此資料夾執行：

```bash
sha256sum --check SHA256SUMS
```
