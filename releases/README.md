# Android 測試版

[下載 日常食動 1.2.0 Debug APK](eat-and-sport-record-1.2.0-debug.apk?raw=true)

- 支援 Android 8.0（API 26）以上。
- 新增多份運動菜單：名稱、說明、動作編輯、上下排序與示範圖片／影片。
- 菜單與每日運動紀錄分開，保留原本的筆記搜尋、統計與影音功能。
- SQLite schema 2 自動升級既有資料；完整 ZIP 備份包含菜單、動作、順序及附件，並可匯入 1.1 版備份。
- 已通過 APK 建置、75 項自動測試及 Android Lint。
- 此檔為 Debug 簽章測試版；真機影音與文件供應程式行為仍需實機驗證。

[舊版 1.1.0 APK](eat-and-sport-record-1.1.0-debug.apk?raw=true)

```bash
sha256sum --check SHA256SUMS
```
